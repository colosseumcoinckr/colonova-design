# MVP 구현 검증 기록

2026-10-20 사용자 구현·검증 요청. 판정 담당: Codex. [범위와 출시 조건](MVP.md)의 P1·P2 구현과 P3의 로컬 검증을 기록한다. P4 전체 합격 기록은 아니다.

## 후보와 환경

- 소스 기준: `a9568dd280ffae6e58d87dfba61afcc56833794c`의 `harsh-horse` 작업 트리. 기존 미커밋 작업을 유지한 상태이며 출시 태그가 아니다.
- 앱: `0.9.0`, 프로토콜 `19`. macOS `26.2`, Apple 실리콘 `arm64`.
- 연결 레포: 테스트용 Node HTTP 앱. 기준 커밋 `2ade8c14978634636d645407142a87baf52e2c73`. 실제 임시 bare git 원격과 메모리 GitHub를 HTTP로 연결했다. 실제 GitHub PR은 만들지 않았다.
- Claude Code: 기존 로그인으로 실제 편집을 실행했다. 검증 자료에는 자격 증명을 남기지 않는다.
- macOS 산출물: `packages/desktop/release/mac-arm64/ColoNova Design.app`. 번들 Node·corepack·git, 웹 정적 파일 포함. 개발용 ad-hoc 서명이며 공증·DMG 설치 검증은 별도다.
- `app.asar` SHA-256: `4a8a5bc840cb331989bd8d81af955a5c8e4a5d91342e6403cb6d41fc9d6a1b78`. `codesign --verify --deep --strict` 통과.

## 증거와 남은 조건

로컬 실행 기록: `/tmp/colonova-mvp-final-suite-v2.log`, `/tmp/colonova-mvp-typecheck-v2.log`, `/tmp/colonova-mvp-biome-v2.log`, `/tmp/colonova-mvp-ui-evidence.json`, `/tmp/colonova-mvp-merged-ui.png`, `/tmp/colonova-mvp-pack-v2.log`. 임시 파일이므로 장기 보관 증거는 위 표의 실행 조건과 SHA를 따른다.

macOS 새 사용자 설치·초대 파일·로그인부터의 N1, 전체 F1–F6 설치 실기, Windows x64 설치본 전체 흐름, 비개발자 베타와 실제 개발자의 PR 확인은 미실행이다. 이 항목을 닫기 전에는 MVP 출시 완료로 표시하지 않는다.

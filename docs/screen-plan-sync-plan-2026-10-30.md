# 화면을 고치면 기획서 초안도 같이 고친다 · 연결 자리 걷기 — 계획과 구현 기록

작성 2026-10-30. 출처: 같은 날 사용자 요청과 결정.

- 요청 「화면 수정 때문에 기획서가 바뀌어야 하면 기획서도 같이 바뀌기를 기획자들이 원한다」 → 결정 「A 방식 — 앱의 초안까지
  자동, Confluence 발행은 사람이」.
- 요청 「연결 탭을 없앨까」 → 결정 「추천대로 — 연결 자리는 걷고 연결 데이터는 남겨 쓰는 곳에서 생기고 보이게」. 같은 요청에
  「기획 탭에서 기획서 문서 작업 · Confluence 기능 최대한 · AI 기반 채팅」이 붙었다.
- 옛 정본(최종 구현 계획)과 계획 문서들은 같은 날 사용자가 정리해 걷었다. 이 문서가 이 결정들의 정본이다. 지금 동작의 진실은
  [사용 설명서](GUIDE.md)와 [개발자 안내](DEVELOPERS.md) 「연결 파일과 같이 고치기」다.

## 0. 결정 기록 (2026-10-30 사용자)

- 화면 요청이 기획 결정을 바꾸면 앱이 이어진 기획서의 **로컬 초안을 자동으로 고친다**. 기획자가 채택을 누르지 않는다.
- **Confluence 발행은 자동으로 하지 않는다.** 화면은 시도와 되돌림이 잦고, 공식본은 사람도 고치는 SSOT 다. 발행은 기존 확인 창
  (개정 사유 · 판 검사 · 원격 초안 보호)을 그대로 지난다.
- 옛 결정에서 바뀐 것: 「자동 채택 제외」 · 「결정 자동 전파 없음」은 화면에서 생긴 기획 변경만 예외다(되돌리기로 거둔다).
  「AI 가 연결을 만들지 않는다」는 그대로다 — 근거 보내기 · 문서 고르기라는 사람의 행동에서 연결이 생긴다. 「발행과 제출은
  별개」는 그대로다 — 제출 확인이 발행 전 초안을 보일 뿐이다.
- 연결 자리(사이드바 `연결` · 지도)는 걷는다. 연결 파일(`plans-map.json`)과 `map.read` · `map.write` 는 남는다.

## 1. 기획자가 보는 한 바퀴

1. 기획서를 `화면에서 확인`으로 보내고 화면 대화에서 `비밀번호를 10자 이상으로 바꿔 줘` 를 보낸다. 화면 AI 가 고치고 앱이 보관한다.
2. 보관이 내려앉으면 앱이 근거로 보낸 문서와 바뀐 화면을 잇고(곁줄 `「…」에 회원가입 화면을 이었어요 · 끊기`), 이 화면에 이어진
   기획서를 찾는다.
3. 기획 AI 가 요청 · 바뀐 화면 · 바뀐 파일 · 이어진 절을 보고 기획 변경이 있는지 본다.
   - 없으면(색 · 간격 · 문구 다듬기) 아무것도 보이지 않는다.
   - 있으면 초안에 바로 들어간다. 결과 카드 아래 곁줄: `「회원가입 정책서」 초안도 같이 고쳤어요` · 요약 한 줄 · `보기` · `되돌리기`
     · `아직 발행 전이에요 · 발행은 기획서에서 해요`.
4. 기획서 칸의 그 문서 대화에도 `화면 요청에서 같이 고쳤어요` 기록이 남고 걸음은 채택이다.
5. 화면을 작업 기록에서 되돌리면 그 뒤에 같이 고친 초안도 되돌아간다. 그 뒤 직접 고친 블록은 그대로다.
6. 제출 확인 창에 `아직 발행 전인 기획서 초안 N개` 가 서고 `기획서에서 발행하기` 가 기획서로 데려간다.
7. 이어진 기획서가 없으면 곁줄의 `기획서 고르기` 로 문서를 고른다 — 그 문서와 화면을 잇고 같이 고친다.

기획서 칸에서는 읽는 문서 곁에도 기획 대화 칸이 선다. 보내면 초안이 열리고 그 말이 기획 대화로 간다. 칸 위의 `이 문서의 화면`
이 이어진 화면을 보이고 `화면 보기` · `끊기` 를 준다.

## 3. 완료 기준

견본 문서와 견본 화면에서 각각 한 번 이상 보인다.

- 정책을 바꾸는 화면 요청 → 이어진 문서의 해당 블록만 초안에 바뀌고, 화면 대화와 기획서 칸에 같은 기록이 선다.
- 정책과 무관한 요청 → 초안 개정이 그대로이고 줄이 서지 않는다.
- 사람이 고치던 블록 → 덮지 않고 변경안으로 남는다.
- 화면 되돌리기 → 같이 고친 블록이 돌아온다. 사람이 그 뒤 고친 블록은 남는다.
- 어느 경우에도 Confluence 쓰기가 일어나지 않는다. 제출 확인이 발행 전 초안 수를 맞게 보인다.

## 4. 남은 판단

- 기획 AI 의 시간 · 비용은 이어진 문서가 있는 화면 턴마다 한 번 더 붙는다. `scripts/bench/` 로 재고, 소음이 크면 켜고 끄는 설정을
  그때 정한다.
- 절 단위 연결(`section`)이 있으면 그 절을 먼저 보게 하고, 없으면 문서 전체다.
- 소개 페이지(`site/`)의 연결 지도 체험은 이번에 고치지 않았다 — 앱과 맞추려면 따로 걷는다.
